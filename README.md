VELMORA — a travel poster for a place that isn't there. Floating isles drift above an amber sea at dusk, under a low retro sun, while the name of the place stands large in the open sky. The poster is drawn entirely by a deterministic Python program (standard library only, no network, no external assets) that writes `/output/entry.png`.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, well under the 1 MiB gate). Two runs produce byte-identical output.
